# ADR-0002: New Project, Not Old ERP Continuation

## Status

Accepted

## Decision

This repository is a new accounting-first project. The old ERP prototype is reference only.

## Context

Real Capita needs a clean accounting and project finance system. The previous ERP prototype must not be treated as the implementation base.

## Consequences

- Do not copy old ERP code, schema, screens, seed data, or fake modules.
- Do not import old private business data.
- Build only confirmed requirements in the current phase.
