# ADR-0005: Initial Single Accountant Role

## Status

Accepted

## Decision

The initial system has only one confirmed role: `ACCOUNTANT`, displayed as `Accountant`.

## Context

At this stage, the only confirmed real user type is AGM sir acting as the main accountant/operator for the accounting software. Other office responsibilities are not confirmed.

## Consequences

- Seed only one role: `ACCOUNTANT`.
- Seed only one local development user: `accountant@realcapita.local`.
- Do not create Data Entry, MD Viewer, Checker, HR, Sales, Payroll, Admin, Super Admin, or other roles.
- Defer all additional roles until Real Capita confirms exact responsibilities.
