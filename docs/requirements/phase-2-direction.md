# Phase 2 Direction Notes

This is a new accounting-first system. The previous Real Capita ERP prototype is reference only and must not be treated as source code for this repository.

AGM sir is the primary actor for the future accounting workflow.

Debit/Credit Voucher will become the core workflow later. Posted voucher lines will later drive Journal, Ledger, Cash Book, Bank Book, Trial Balance, and Financial Statements.

No HR, CRM, payroll, full ERP, project operations, customer/vendor, reporting, or business workflow modules are included in Phase 0.
